# Workout Tracker A–C

A simple offline mobile workout tracker for Workout A, B, and C.

## Use
1. Open `index.html` in a mobile browser.
2. Choose Workout A, B, or C.
3. Enter the weight used, reps for each set, and optional RIR.
4. Tap Save workout.
5. Use Home for your bodyweight/waist check-in and History to review sessions.

Your data is stored locally in the browser using localStorage.

## Phone shortcut
On iPhone/Android, use the browser's "Add to Home Screen" / "Add to Home Screen" option after opening the file.

Note: browser support for opening local files and adding them as home-screen apps varies by device. The tracker itself works as a normal mobile web page.
